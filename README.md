# Femtum SDK / API Examples

Usage examples for the [Femtum SDK](https://pypi.org/project/femtum-sdk/), demonstrating hardware and datastore APIs.

## Prerequisites

- **Python** 3.11–3.13
- **Poetry** (recommended) or pip with a virtual environment

## Setup

```bash
cd python
poetry install
```

This installs the `femtum-sdk` dependency and dev tools (Jupyter, Pillow).

## Project structure

```
python/
  notebooks/           # Jupyter notebooks
    laser_execute.ipynb
    laser_head_camera.ipynb
    fetch_laser_executions.ipynb
  pyproject.toml
```
